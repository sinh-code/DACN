# ☕ Coffee Shop Mobile App

## 📌 Giới thiệu

Ứng dụng di động **Coffee Shop** là một hệ thống hỗ trợ khách hàng đặt cà phê trực tuyến một cách nhanh chóng và tiện lợi.
Ứng dụng được phát triển trong khuôn khổ **đồ án chuyên ngành**, tập trung vào trải nghiệm người dùng và hiệu năng hệ thống.

---

## 🎯 Mục tiêu

* Xây dựng ứng dụng bán cà phê trên nền tảng di động
* Tối ưu trải nghiệm người dùng (UI/UX)
* Quản lý đơn hàng hiệu quả
* Áp dụng kiến thức về lập trình, cơ sở dữ liệu và kiểm thử phần mềm

---

## 🚀 Tính năng chính

### 👤 Người dùng

* Đăng ký / Đăng nhập tài khoản
* Xem danh sách sản phẩm (cà phê, đồ uống)
* Tìm kiếm và lọc sản phẩm
* Thêm vào giỏ hàng
* Đặt hàng và thanh toán
* Xem lịch sử đơn hàng

### 🛠️ Quản trị (Admin)

* Quản lý sản phẩm
* Quản lý đơn hàng
* Quản lý người dùng
* Thống kê doanh thu

---

## 🛠️ Công nghệ sử dụng

* Frontend: ( Android Java )
* Backend: (Spring Boot / Node.js / Firebase)
* Database: (MySQL / Firebase Realtime DB)
* Công cụ: Git, Postman, JMeter
